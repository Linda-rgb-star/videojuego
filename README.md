# videojuego
Primer punto taller 4 - Programación 1 SC

Un videojuego registra los personajes creados por los jugadores. Cada personaje tiene un nombre, un nivel y una cantidad de puntos de vida. El nivel solo puede aumentar mediante las acciones del juego y los puntos de vida no pueden ser menores que 0 ni mayores que el máximo permitido. El jugador puede consultar los datos de su personaje, pero no modificar directamente el nivel ni los puntos de vida. Cada personaje posee un inventario con los objetos que lleva consigo. Si se elimina un personaje, su inventario también debe desaparecer, mientras que el jugador continúa existiendo.
